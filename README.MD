# Project notes

## Content writing convention

All news content must follow the approved format in [DOCS/NEWS_CONTENT_CONVENTION.MD](DOCS/NEWS_CONTENT_CONVENTION.MD).

This is the checkpoint rule for article writing and parsing:
- use one format per job only
- headings use #, ##, ###
- unordered lists use *
- ordered lists use 1.
- URLs are pasted as full http/https links
- italics use __text__
- bold uses **text**
